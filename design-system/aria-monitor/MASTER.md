# Aria monitor

Web operations console on Apollo, no authentication at maintainer request.
Only bounded client controls are exposed: input mute and offline-list cleanup.
First tab: live logs, incoming STT, engine steps, tools, exact response, audio readiness.

UI UX Pro Max local search verified `cyberpunk-ui` and `hud-sci-fi-fui` styles.
Use dark charcoal/navy, Matrix green and cyan accents, thin structural lines,
restrained HUD geometry, system sans and monospace. No remote fonts or dependencies.
The general design-system search returned operations guidance but landing-page
sections; those marketing sections are not applicable and are omitted.

Keep log text readable, body contrast at least 4.5:1, visible keyboard focus,
44px controls, responsive single-column mobile layout, reduced-motion support.
No glitching text, endless animated matrix rain, fake waveforms, or invented metrics.
Link state means monitor connection, not assistant readiness. Show source, last
event age, reconnect state and bounded recent-history window explicitly.
Pause and filters affect only this browser. Never send device actions.

2026-10-18 density update: prioritize visible logs over decorative top sections.
Use one 60px header/status bar, compact metrics, expandable help, and a flexible
log viewport. Bound long client collections with scrolling; keep 44px controls
and visible status text. Empty client collections collapse. Responsive layouts
must remain usable at 375px width and in short landscape windows without horizontal
overflow. UI UX Pro Max's compact-label guidance applies; the broad dashboard-density
search was off-topic and was not used as design authority.
